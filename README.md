# Delul

## 📌 Описание проекта

**Delul** — учебный проект на языке Python, созданный для изучения основ программирования, работы с Git и GitHub, а также управления версиями программного кода.

Проект демонстрирует процесс разработки простой программы, создания отдельных веток, внесения изменений и объединения результатов работы.

## 🎯 Цель проекта

Научиться использовать GitHub для хранения программного кода, управления изменениями и организации разработки.

## 🚀 Основные возможности

- Запуск простой программы на Python.
- Работа с файлами проекта.
- Создание и редактирование веток Git.
- Отслеживание изменений с помощью коммитов.
- Объединение веток через Pull Request.

## 🛠 Используемые технологии

- **Python** — язык программирования.
- **Git** — система контроля версий.
- **GitHub** — платформа для хранения и совместной разработки кода.
- **Markdown** — язык разметки для документации.
