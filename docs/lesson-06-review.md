## Must story → endpoint → таблицы

| История | Основные эндпоинты | Таблицы |
|---------|-------------------|---------|
| US-1 | POST /api/quizzes; POST /api/quizzes/{quiz_id}/publish | users, categories, quizzes, questions, answer_options |
| US-2 | POST /api/quizzes/{quiz_id}/attempts; POST /api/attempts/{attempt_id}/submit | users, quizzes, attempts, attempt_answers, questions, answer_options |
| US-3 | POST /api/attempts/{attempt_id}/submit; GET /api/quizzes/{quiz_id}/results | attempts, attempt_answers, answer_options, results, users, quizzes |
| US-4 | POST /api/quizzes/{quiz_id}/release-results; GET /api/attempts/{attempt_id}/result | quizzes, attempts, results, attempt_answers, questions, answer_options |

## Открытые замечания

- Пути `publish`, `submit`, `release-results` являются операциями с глаголами. Это отмечено в проверке API; если преподаватель требует только ресурсные пути, контракт нужно отдельно переработать и согласовать описание PATCH.
- Вход через Keycloak предусмотрен, но способ стабильной привязки профиля и источник ролей ещё не утверждены.
- Имя и группа работы читаются из текущего профиля; исторические снимки отдельно не реализованы в модели.
- Это проверка проектных документов, а не тест работающего backend.
